Media tools for coding agents: bring footage into a project whole, map its audio and picture, see it as contact sheets, transcribe it (locally or through an API), and plan a recut that plays ranges of the original file, with `smoove new --template recut` and `cut_plan`. Asset tools search Openverse, add images and sounds with their credits, and take screenshots of pages.

The agent package gains the media tools' result types and paths, and `captureScreenshot` in its server entry.
