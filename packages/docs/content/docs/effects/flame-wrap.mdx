title: flameWrap

Fire wrapped around a node, with heat distortion, sparks, a molten rim, smoke,
and scorching. Flames climb off the top edge, glow at the sides, eat into the
edge, and char and light whatever survives inside.

<Demo name="flame-wrap" />

```ts
import { Block } from "@smoove/core";
import { flameWrap } from "@smoove/effects";

const card = new Block({ width: 620, padding: 48, cornerRadius: 40 });
card.effects([flameWrap({ radius: 40, height: 150, sparks: 1.8, melt: 5 })]);
```

## Ignite it

The burn loops on its own. To ignite something, animate `intensity` from 0:

```ts
const fire = flameWrap({ intensity: 0 });
card.effects([fire]);

seq.register((frame) => {
  fire.intensity = interpolate(frame, [0, 20], [0, 1], {
    extrapolateLeft: "clamp",
    extrapolateRight: "clamp",
  });
});
```

At `intensity: 0` the effect switches off and the node draws through the normal
path, so an unlit card costs nothing.

## Two shapes

`shape` decides what the flames follow.

`box`, the default, wraps the node's bounding box with `radius` rounding its
corners. Set `radius` to the same value as your `Block`'s `cornerRadius` and the
burn line follows the card exactly. Nothing is derived from the node's pixels,
so this is the cheaper of the two.

`silhouette` reads the outline from the node's own alpha instead, so a burning
`Text` burns letter by letter and a cutout PNG burns along its cutout, with no
per-shape configuration. It costs a distance field, rebuilt whenever the node's
content changes, and ignores `radius`.

```ts
title.effects([flameWrap({ shape: "silhouette" })]);
```

## Parameters you will reach for

`color` is the flame tint as linear RGB in 0 to 1. `intensity` scales the whole
effect and doubles as the ignition control. `height` is how far flames climb
above an edge, in px, and `speed` is the flow rate. `turbulence` bends the
flames, and `sparks` sets how bright the embers are.

## Full reference

| Parameter | Type | Default | What it does |
| --- | --- | --- | --- |
| `shape` | `"box" \| "silhouette"` | `"box"` | Whether the flames follow the node's rounded box or its alpha |
| `color` | `[number, number, number]` | `[0.31, 0.54, 1]` | Flame tint, linear RGB in 0 to 1 |
| `intensity` | `number` | `0.5` | Overall strength, 0 to 3. Zero disables the effect |
| `height` | `number` | `170` | Flame reach above an edge, px |
| `spread` | `number` | `8` | Glow reach at the sides and below, px |
| `radius` | `number` | `40` | Corner radius of the burning outline, px. `box` only |
| `speed` | `number` | `0.25` | Flow rate of the fire |
| `scale` | `number` | `0.75` | Flame detail, 0 broad to 1 fine |
| `turbulence` | `number` | `0.5` | Wave amplitude, 0 to 1 |
| `turbulenceScale` | `number` | `0.5` | Wave frequency, 0.2 to 3 |
| `turbulenceReach` | `number` | `25` | How far the heat warp extends, px |
| `sparks` | `number` | `1.5` | Spark brightness, 0 to 3. Zero turns them off |
| `sparkSize` | `number` | `0.35` | Spark size multiplier |
| `sparkDensity` | `number` | `1` | Spark count, 0.3 to 2.5 |
| `sparkSpeed` | `number` | `1` | Spark rise and flicker rate |
| `rim` | `number` | `2.5` | Molten edge glow, 0 to 3 |
| `melt` | `number` | `4.5` | How far the burning edge eats into the node, px |
| `distortion` | `number` | `10` | Heat shimmer displacement, px |
| `smoke` | `number` | `1.5` | Smoke amount, 0 to 2 |
| `ember` | `number` | `2` | Burnt edge glow, 0 to 2 |
| `scorch` | `number` | `0` | Charring of what survives, 0 to 2 |

Values outside a range clamp rather than throw, so an easing overshoot is safe.

## What it costs

The shader pays for the node's box plus the flame reach around it, so put
`flameWrap` on the node you want burning rather than on a `Sequence`. A centred
`Text` at full stage width is the trap: under `silhouette` the fire still lands
only on the letters while the shader pays for the whole frame, and under `box`
the flames wrap the stage. See [Keep the node's box
tight](/docs/effects#keep-the-nodes-box-tight).

`flameWrap` needs WebGL. Where none is available the pass is skipped and the
node draws as usual.
