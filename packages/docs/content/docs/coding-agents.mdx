smoove's API is built on concepts a model already knows: keyframes, a
timeline, flexbox layout, familiar shape names. That makes it something you
can hand to a coding agent and get a working composition back, not just
autocomplete.

## Prerequisites

- Node.js 18.17 or later.
- A coding agent CLI: Claude Code, Cursor, Codex, or similar.

## Start a new project

```bash
npm create smoove
```

Pick **studio** for the full timeline and props UI, or **composition** for a
single scene. The studio template installs the `smoove-video` skill for you,
and the composition template offers to: that's what teaches your agent the
mental model (frame clock, range-gated sequences, `interpolate`-driven
updaters) before it writes a line of code. See [Agent skills](/docs/skills)
for what the skill covers and how to add it later.

## Work in the studio

A studio project ships the `smoove` command, and its `AGENTS.md` tells your
agent how to use it. Start your agent in the project folder and describe the
video in plain language: what's on screen, what moves, how long it runs.

The agent starts the studio itself and gives you the URL:

```bash
npx smoove start
```

Open it beside your terminal. The studio fits a narrow window: below about
640 pixels wide, the library and the inspector fold into drawers, and the
stage takes the column.

While it works, the agent looks at its own frames instead of rendering a
video. Each command writes a PNG and prints its path:

```bash
npx smoove sheet --comp my-video          # one tile per beat
npx smoove snap --comp my-video --at hook # one moment, by beat name
```

Looking never moves your playhead. When you're happy, ask for the video, and
the agent renders it through the studio's queue:

```bash
npx smoove render --comp my-video
```

## Work with the composition template

```bash
cd my-video
npm run dev
```

Open the printed URL and leave it running. `<smoove-player>` hot-reloads on
every save, so you'll see each change the agent makes as it makes it. In a
separate terminal, start your coding agent in the project and describe the
video; it edits `src/composition.ts`.
